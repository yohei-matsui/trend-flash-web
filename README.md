# 業界トレンド速報メーカー

ジャンル（＝担当クライアントの業界）を選ぶだけで、**直近の新規・伸びているYouTube動画**を自動で洗い出し、
そのまま**Chatworkに貼れる「業界トレンド速報」テキスト**をワンクリックで生成するセルフサーブ型のWebツール。

日々の定例以外の細やかなコミュニケーションとして速報をクライアントに届け、関係性を深める——
その運用を「誰でも・同じ品質で・月次で」続けられるように仕組み化したものです。

## 使い方（利用者向け）

1. サイトを開く（Vercelのデプロイ URL）
2. **YouTube Data API キー**を入力（ブラウザ内にのみ保存。サーバーには送られません）
   - キーの取得方法: Google Cloud Console → YouTube Data API v3 を有効化 → APIキーを発行
3. **ジャンル**を選ぶ（担当業界に合わせて追加・編集も可能。設定はブラウザに保存されます）
4. 期間・最低再生数・拡散率などを調整して「**トレンド速報を作成**」
5. 生成された**速報テキストをコピー**してChatworkへ。一覧はCSVでも出力できます

## 仕組み

- `app/api/trend/route.ts` … 複数キーワードを直近N日・伸び順で検索し、
  **拡散率（再生数 ÷ そのチャンネルの平常再生数の中央値）**を算出。規模に依らず「本当に伸びた動画」を抽出。
- `app/page.tsx` … ジャンルプリセット管理・フィルタ・速報テキスト生成のUI。

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Next.js（App Router）。Vercelにそのままデプロイできます。

## クォータの注意

YouTube Data API の `search.list` は 1回100ユニット（1日既定10,000）。
**キーワード数 × 100** が主なコスト。ジャンルあたり2〜4キーワードが目安です。
APIキーは利用者ごとに各自のものを使うため、消費は自然に分散されます。
